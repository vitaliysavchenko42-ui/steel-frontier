# Стальной Рубеж

Браузерная танковая аркада с бесконечными уровнями. Полностью собственный код и графика (canvas + Web Audio), без внешних ассетов и без заимствований у правообладателей.

## Играть
https://vitaliysavchenko42-ui.github.io/steel-frontier/

## Управление
- Стрелки / WASD — движение, ПРОБЕЛ — огонь, P — пауза
- На телефоне: экранный D-pad и кнопка ОГОНЬ

## Особенности
- Бесконечные уровни: каждая карта генерируется по номеру (детерминированный сид), 4 уровня проверки связности
- 4 типа врагов (обычный, быстрый, снайпер, бронированный) с маршрутным ИИ — идут к штабу, пробивают кирпич
- 6 бонусов: граната, каска, звезда (3 ступени апгрейда), лопата (бетон штаба), танк (+жизнь), часы (фриз)
- Рост сложности: число врагов, скорость, меткость растут с уровнем
- Синтез звука на Web Audio: выстрелы, взрывы, гул движка, собственная заставочная тема

## Структура
- `js/` — логика (детерминированная, тестируется в Node) и оболочка (canvas, UI, звук)
- `tests/` — автотесты логики, ИИ, боя и симуляции (Node, без зависимостей)

## Тесты
```bash
node tests/engine.test.js && node tests/ai.test.js && node tests/game.test.js && node tests/sim.test.js && node tests/ui.test.js
```

## Лицензия и права
Механика вдохновлена классикой жанра, но код, графика и музыка — собственные. Торговые марки третьих лиц не используются.
