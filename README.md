# Стальной Рубеж

Браузерные «танчики»: single-player ремейк классической формулы — защита базы, разрушаемые стены, враги, бонусы и апгрейды.

## Текущее состояние (M1 — прототип)

- Поле 26×26 тайлов (416×416), танк 2×2 тайла, пуля 1×1 тайл.
- Тайлы: кирпич (разрушается), сталь, вода (пули пролетают), лес (танки скрываются), стены базы, база.
- Игрок: 3 жизни, возрождение 2 с, щит 2 с.
- Враги: 5 на уровень, до 3 одновременно, простое ИИ (цель игрок/база, объезд препятствий).
- Управление: WASD/стрелки + Space/Enter; на телефоне — D-pad и кнопка огня.
- Поражение: штаб уничтожен или жизни кончились.

## Запуск

Статический хостинг (GitHub Pages). Никакой сборки: ESM-модули в `src/`.

- Прод: https://vitaliysavchenko42-ui.github.io/steel-frontier/
- Локально: `python3 -m http.server` в корне и открыть `http://localhost:8000`.

## Структура

```
index.html      — точка входа
css/style.css   — стили, safe-area, touch-контролы
src/config.js   — константы (сетка, тайлы, скорости)
src/level.js    — карта уровня, спавны, парсер JSON-конфига
src/input.js    — клавиатура + сенсор
src/engine.js   — логика 60 Гц: танки, пули, коллизии, ИИ
src/render.js   — процедурный пиксель-арт на Canvas 2D
src/sound.js    — WebAudio SFX
src/main.js     — цикл, HUD, оверлеи
```

## Лицензии

Все ассеты оригинальные, отрисованы кодом. Спрайты, звуки и уровни Battle City / Nintendo не используются.
